# Roadmap MVP (8-10 semanas)

## Fase 1 (Semana 1-2): Base técnica
- Inicializar backend y frontend.
- Configurar PostgreSQL + Redis.
- Webhook WhatsApp con verificación.

## Fase 2 (Semana 3-4): Conversación IA
- Motor conversacional con memoria corta.
- Integración OpenAI (primero) + interfaz proveedor.
- Reglas de fallback a agente humano.

## Fase 3 (Semana 5-6): RAG empresarial
- Ingesta de documentos.
- Embeddings + búsqueda semántica.
- Citas internas para respuestas más confiables.

## Fase 4 (Semana 7-8): Panel admin
- Editor de prompt y conocimiento.
- Simulador de conversaciones.
- Roles (admin/editor/visor).

## Fase 5 (Semana 9-10): Observabilidad y hardening
- Métricas de negocio y costos.
- Alertas y auditoría.
- Pruebas de carga y seguridad.
